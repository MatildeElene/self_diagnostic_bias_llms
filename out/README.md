# Output Overview

This directory contains the figures and tables generated from the analyses provided with the study. The outputs summarize the experimental results and are generated from the released data in [`/data`](../data) and [`/results`](../results).

The corresponding analysis and visualization scripts used to reproduce these outputs are available in [`/src`](../src).

| Folder/File | Description |
|---|---|
| [`figures/`](./figures) | Contains figures visualizing the experimental results across studies, ADHD subtypes, and demographic cueing conditions. |
| [`tables/`](./tables) | Contains summary tables reporting the experimental results and clinically informed proxy distributions. |

📌 For a general project overview, see the [main README](../README.md).
