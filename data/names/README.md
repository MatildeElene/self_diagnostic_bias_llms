# U.S. Social Security Administration Baby Names Data

This directory contains the U.S. Social Security Administration
Popular Baby Names dataset used for selection of gender-indicative names.

Source:
U.S. Social Security Administration, Popular Baby Names.

The original data are distributed by the Social Security Administration
as public-use government data. The archive is included here to preserve
the version used in the study.

For documentation and the most recent version, see:
https://www.ssa.gov/oact/babynames/limits.html

The repository's CC BY 4.0 license applies to the authors' original
materials and does not assert ownership over the SSA source data.
