# Results

This directory contains model responses and derived evaluation outputs for the two studies.

## Structure

- `responses/` — Raw model responses from each experimental condition.
- `metrics/` — Derived CAT metrics and statistical evaluation outputs.
- `summaries/` — Aggregated outputs used to summarize results across experimental conditions.

## `responses/`

Contains the model-level responses generated for each study and cueing condition:

- `s1_ex_responses.csv` — Study 1, explicit gender cueing
- `s1_im_responses.csv` — Study 1, implicit gender cueing
- `s2_ex_responses.csv` — Study 2, explicit gender cueing
- `s2_im_responses.csv` — Study 2, implicit gender cueing

## `metrics/`

Contains condition-specific CAT evaluation metrics and summarized statistical analyses:

- `s1_ex_metrics.csv` — Study 1, explicit gender cueing
- `s1_im_metrics.csv` — Study 1, implicit gender cueing
- `s2_ex_metrics.csv` — Study 2, explicit gender cueing
- `s2_im_metrics.csv` — Study 2, implicit gender cueing
- `summary_metrics.csv` — Aggregated evaluation metrics across studies and cueing conditions
- `subtype_analyses.csv` — Subtype-level chi-square goodness-of-fit analyses comparing observed gender-associated response distributions with the clinically informed proxy distributions.

## `summaries/`

Contains aggregated result summaries used for reporting and visualization.
